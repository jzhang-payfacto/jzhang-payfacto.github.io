Operation and privacy

This page utilizes JavaScript executed within your web browser to perform in-browser decoding. No network connections are established during this process, ensuring that your data remain exclusively within the confines of your web browser. This claim can be independently verified by examining the page's source code.

Running this page offline

This web page is completely self-contained. It does not rely on any external files; all JavaScript and CSS necessary for its functionality are included directly in its source code. To run this page offline on your system, simply save it as an .html file and open it in your web browser.

Decode TLV data

Paste EMV records encoded in tag-length-value format to see each tag, its name and its value.

Spaces, line breaks and colons are ignored. Example: 6F1A840E315041592E5359532E4444463031A5088801025F2D02656E
